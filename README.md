# Jarvis AI Assistant

Jarvis is a voice-controlled personal assistant built with Python.  
It can recognize speech, respond with voice, open websites, run apps, fetch news, and answer questions using OpenAI.

## ✨ Features
- Speech recognition
- Text-to-speech (pyttsx3 or gTTS + pygame)
- Opens websites (Google, YouTube, Facebook, etc.)
- Launches local apps (Notepad, Calculator, Chrome)
- Tells time and date
- Reads top news headlines (via NewsAPI)
- AI-powered responses (OpenAI GPT)
